# 代码修改总结 - 基于新策划案的成就系统重构

## 修改概述

根据最新的策划案，我们对游戏系统进行了全面的重构，主要包括：

1. **游戏机制根本性变化**：从百分比进度系统改为时间+状态值系统
2. **成就系统重新设计**：基于新的剧情线路而非行为计数
3. **动作系统调整**：添加时间消耗和状态值要求
4. **数据结构更新**：支持新的游戏机制

## 详细修改内容

### 1. 游戏状态类型修改 (src/types/index.ts)

**修改原因**：
- 原系统使用百分比进度（hungry: 0-100, needPoop: 0-100）
- 新系统使用点数系统（hungry: 0-5, energy: 0-5）
- 需要添加时间系统（12小时游戏时长）

**具体修改**：

### 4. 成就系统逻辑重构 (src/systems/AchievementSystem.ts)

**修改原因**：
- 原系统使用简单的计数器检查
- 新系统需要复杂的条件检查（时间、状态值、物品收集等）

**具体修改**：
```typescript
// 重新设计条件检查方法
private checkPlayCompletion(condition: AchievementCondition): boolean {
    // 检查是否收集了所有玩具
    const hasAllToys = condition.requiredToys.every(toyId => 
        this.gameState.inventory.includes(toyId)
    );

    // 检查是否进行了所有玩耍交互
    const hasAllInteractions = condition.requiredInteractions.every(interactionId => 
        this.gameState.achievementCounters.playInteractionCount > 0
    );

    return hasAllToys && hasAllInteractions;
}
```

### 5. 动作系统重构 (src/systems/ActionSystem.ts)

**修改原因**：
- 需要检查动作是否可执行（状态值要求）
- 需要消耗时间和状态值
- 需要更新新的成就计数器

**具体修改**：
```typescript
// 添加动作可执行性检查
private canExecuteAction(action: Action): boolean {
    // 检查饥饿值要求
    if (action.hungryRequirement && this.gameState.hungry < action.hungryRequirement) {
        return false;
    }
    
    // 检查精力值要求
    if (action.energyRequirement && this.gameState.energy < action.energyRequirement) {
        return false;
    }
    
    // 检查时间是否足够
    const timeCost = action.timeCost || (action.category === 'simple' ? 30 : 60);
    if (this.gameState.timeRemaining < timeCost) {
        return false;
    }
    
    return true;
}

// 添加成本消耗
private consumeActionCosts(action: Action): void {
    // 消耗时间
    const timeCost = action.timeCost || (action.category === 'simple' ? 30 : 60);
    this.gameState.currentTime += timeCost;
    this.gameState.timeRemaining -= timeCost;
    
    // 消耗精力值
    if (action.energyCost) {
        this.gameState.energy -= action.energyCost;
    }
    
    // 恢复状态值
    if (action.hungryRestore) {
        this.gameState.hungry = Math.min(5, this.gameState.hungry + action.hungryRestore);
    }
}
```

## 新的成就系统设计

### 主线剧情成就（单局内完成）

1. **【玩耍时光】** - 收集所有猫玩具并进行所有玩耍交互
2. **【猫中哈士奇】** - 破坏所有昂贵的可破坏物
3. **【两脚兽的盟友】** - 无破坏行为 + 门口迎接
4. **【再见了两脚兽今天我就要远航】** - 离家出走路线
5. **【走路小心点】** - 布置陷阱陷害铲屎官
6. **【后勤官】** - 准备材料构筑堡垒

### 成就条件类型

- **时间限制**: 必须在特定时间前完成
- **状态要求**: 需要特定饥饿值/精力值
- **状态消耗**: 某些行动需要消耗状态值
- **路径完成**: 完成特定系列行动

## 修改的影响

### 正面影响

1. **更好的策略性**: 玩家需要合理规划时间和状态值
2. **更符合策划案**: 完全按照新策划案的设计理念
3. **更好的可扩展性**: 新系统更容易添加新的成就和机制
4. **更好的用户体验**: 时间限制增加了紧张感

### 需要注意的问题

1. **平衡性**: 需要测试时间和状态值的平衡
2. **兼容性**: 旧存档可能无法兼容新系统
3. **UI更新**: 需要更新UI以显示新的状态值和时间

## 测试建议

1. **功能测试**: 验证所有新机制是否正常工作
2. **平衡测试**: 测试时间和状态值的平衡性
3. **成就测试**: 验证所有新成就的解锁条件
4. **边界测试**: 测试时间用完、状态值耗尽等情况

## 总结

这次重构使游戏系统完全符合新策划案的设计理念，提供了更好的策略性和可玩性。虽然修改幅度较大，但这是必要的，因为新策划案的游戏机制与原有系统有根本性的不同。
