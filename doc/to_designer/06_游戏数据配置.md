# 游戏数据配置详解

## 🎯 什么是游戏数据配置？

游戏数据配置是游戏的"总指挥"，它定义了游戏的初始状态、文件引用关系、场景列表等核心信息。这是所有其他配置文件的入口点。

## 📁 配置文件位置

游戏数据配置在 `public/assets/data/gameData.json` 文件中。

## 🏗️ 游戏数据配置结构

游戏数据配置包含以下主要部分：

```json
{
    "initialState": {
        // 游戏初始状态
    },
    "itemsFile": "文件路径",
    "actionsFile": "文件路径",
    "itemInteractionsFile": "文件路径",
    "scenes": {
        // 场景文件路径
    }
}
```

## 📝 字段说明

### 主要字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `initialState` | 对象 | ✅ | 游戏初始状态 | 见下方说明 |
| `itemsFile` | 字符串 | ✅ | 物品配置文件路径 | `"assets/data/items.json"` |
| `actionsFile` | 字符串 | ✅ | 动作配置文件路径 | `"assets/data/actions.json"` |
| `itemInteractionsFile` | 字符串 | ✅ | 物品交互配置文件路径 | `"assets/data/item_interactions.json"` |
| `scenes` | 对象 | ✅ | 场景配置文件路径 | 见下方说明 |

## 🎮 实际例子

### 完整的gameData.json配置
```json
{
    "initialState": {
        "currentLocation": "living_room",
        "currentTime": 0,
        "timeRemaining": 720,
        "hungry": 3,
        "energy": 3,
        "progress": {
            "humanComingHome": 0
        },
        "flags": {
            "door_to_hall_open": true,
            "door_to_balcony_open": false,
            "room_a_locked": true,
            "room_b_locked": true,
            "room_c_locked": true
        },
        "inventory": [],
        "actionLog": [],
        "history": [],
        "achievements": {},
        "achievementCounters": {
            "toyCollectionCount": 0,
            "playInteractionCount": 0,
            "expensiveItemDestroyCount": 0,
            "balconyVisited": 0,
            "neighborEscape": 0,
            "trapSetupCount": 0,
            "materialPreparationCount": 0,
            "greetingAtDoor": 0,
            "noDestructionFlag": false
        }
    },
    "itemsFile": "assets/data/items.json",
    "actionsFile": "assets/data/actions.json",
    "itemInteractionsFile": "assets/data/item_interactions.json",
    "scenes": {
        "living_room": "assets/data/scenes/living_room.json",
        "hallway": "assets/data/scenes/hallway.json",
        "balcony": "assets/data/scenes/balcony.json"
    }
}
```

## 🔧 初始状态详解

### 基础状态字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `currentLocation` | 字符串 | 当前所在场景 | `"living_room"` |
| `currentTime` | 数字 | 当前时间（分钟） | `0` |
| `timeRemaining` | 数字 | 剩余时间（分钟） | `720` |
| `hungry` | 数字 | 饥饿值（0-5） | `3` |
| `energy` | 数字 | 精力值（0-5） | `3` |

### 进度系统字段

```json
{
    "progress": {
        "humanComingHome": 0  // 人类回家进度
    }
}
```

### 标志系统字段

```json
{
    "flags": {
        "door_to_hall_open": true,      // 过道门是否开启
        "door_to_balcony_open": false,  // 阳台门是否开启
        "room_a_locked": true,          // 房间A是否锁定
        "room_b_locked": true,          // 房间B是否锁定
        "room_c_locked": true           // 房间C是否锁定
    }
}
```

### 背包和日志字段

```json
{
    "inventory": [],        // 背包中的物品
    "actionLog": [],        // 动作日志
    "history": []           // 游戏历史
}
```

### 成就系统字段

```json
{
    "achievements": {},     // 已解锁的成就
    "achievementCounters": {
        "toyCollectionCount": 0,        // 收集的玩具数量
        "playInteractionCount": 0,      // 玩耍交互次数
        "expensiveItemDestroyCount": 0, // 昂贵物品破坏数量
        "balconyVisited": 0,            // 阳台访问次数
        "neighborEscape": 0,            // 邻居家逃脱次数
        "trapSetupCount": 0,            // 陷阱设置数量
        "materialPreparationCount": 0,  // 材料准备数量
        "greetingAtDoor": 0,            // 门口迎接次数
        "noDestructionFlag": false      // 无破坏标志
    }
}
```

## 🔧 常见修改

### 修改初始场景
```json
// 修改前
"currentLocation": "living_room"

// 修改后
"currentLocation": "hallway"
```

### 修改游戏时长
```json
// 修改前
"timeRemaining": 720

// 修改后
"timeRemaining": 600  // 减少到10小时
```

### 修改初始状态值
```json
// 修改前
"hungry": 3,
"energy": 3

// 修改后
"hungry": 5,  // 更饿
"energy": 5   // 更精力充沛
```

### 修改门的状态
```json
// 修改前
"flags": {
    "door_to_balcony_open": false
}

// 修改后
"flags": {
    "door_to_balcony_open": true  // 阳台门开启
}
```

### 添加初始物品
```json
// 修改前
"inventory": []

// 修改后
"inventory": ["fish_item", "key_item"]  // 初始拥有小鱼干和钥匙
```

### 添加新场景
```json
// 修改前
"scenes": {
    "living_room": "assets/data/scenes/living_room.json",
    "hallway": "assets/data/scenes/hallway.json",
    "balcony": "assets/data/scenes/balcony.json"
}

// 修改后
"scenes": {
    "living_room": "assets/data/scenes/living_room.json",
    "hallway": "assets/data/scenes/hallway.json",
    "balcony": "assets/data/scenes/balcony.json",
    "kitchen": "assets/data/scenes/kitchen.json"  // 添加厨房场景
}
```

## ➕ 添加新场景

### 步骤1：创建场景配置文件
在 `public/assets/data/scenes/` 文件夹中创建新的场景文件，例如 `kitchen.json`。

### 步骤2：在gameData.json中注册场景
```json
{
    "scenes": {
        "living_room": "assets/data/scenes/living_room.json",
        "hallway": "assets/data/scenes/hallway.json",
        "balcony": "assets/data/scenes/balcony.json",
        "kitchen": "assets/data/scenes/kitchen.json"  // 添加新场景
    }
}
```

### 步骤3：在场景中添加导航
在其他场景中添加导航到新场景的入口：
```json
{
    "objects": {
        "to_kitchen": {
            "x": 1200,
            "y": 400,
            "image": "placeholder_arrow_right_64x64",
            "name": "厨房",
            "look": "那边是厨房。",
            "navTo": "kitchen"
        }
    }
}
```

## 📊 状态值系统详解

### 饥饿值 (hungry)
- 范围：0-5
- 0 = 非常饿
- 5 = 非常饱
- 某些动作会消耗饥饿值
- 吃食物可以恢复饥饿值

### 精力值 (energy)
- 范围：0-5
- 0 = 非常疲惫
- 5 = 精力充沛
- 某些动作会消耗精力值
- 睡觉可以恢复精力值

### 时间系统
- `currentTime`：从游戏开始到现在的时间（分钟）
- `timeRemaining`：剩余的游戏时间（分钟）
- 每个动作都会消耗时间
- 时间耗尽游戏结束

### 进度系统
- `humanComingHome`：人类回家的进度
- 某些动作会增加这个进度
- 进度达到某个值会触发特殊事件

## ⚠️ 注意事项

### 文件路径要求
- 所有文件路径必须正确
- 路径相对于 `public/` 文件夹
- 确保引用的文件存在
- 路径区分大小写

### 状态值范围
- 饥饿值和精力值必须在0-5范围内
- 时间值不能为负数
- 计数器值通常从0开始

### 场景ID要求
- 场景ID必须唯一
- 场景ID要与场景文件名对应
- 导航时使用的场景ID必须存在

### 物品ID要求
- 背包中的物品ID必须在 `items.json` 中定义
- 不能引用不存在的物品

## 🔄 与其他系统的关联

### 与场景系统的关联
```json
{
    "scenes": {
        "living_room": "assets/data/scenes/living_room.json"  // 引用场景文件
    }
}
```

### 与物品系统的关联
```json
{
    "itemsFile": "assets/data/items.json",  // 引用物品文件
    "inventory": ["fish_item"]              // 使用物品ID
}
```

### 与动作系统的关联
```json
{
    "actionsFile": "assets/data/actions.json"  // 引用动作文件
}
```

### 与成就系统的关联
```json
{
    "achievementCounters": {
        "toyCollectionCount": 0  // 成就系统使用的计数器
    }
}
```

## 💡 策划建议

### 初始状态设计原则
1. **平衡性** - 初始状态要平衡
2. **挑战性** - 提供适当的挑战
3. **引导性** - 引导玩家开始游戏
4. **多样性** - 提供不同的起始选择

### 时间设计建议
1. **合理分配** - 时间要足够完成主要目标
2. **压力适中** - 提供适当的压力
3. **策略性** - 让玩家需要做出选择
4. **节奏感** - 控制游戏的节奏

### 状态值设计建议
1. **渐进性** - 状态值变化要渐进
2. **关联性** - 不同状态值之间可以有关联
3. **平衡性** - 状态值要平衡
4. **反馈性** - 提供清晰的反馈
