# 物品配置详解

## 🎯 什么是物品配置？

物品配置定义了游戏中所有可以收集、使用、交互的物品。比如小鱼干、钥匙、玩具等。

## 📁 配置文件位置

物品配置在 `public/assets/data/items.json` 文件中。

## 🏗️ 物品配置结构

每个物品都有以下基本结构：

```json
{
    "物品ID": {
        "id": "物品ID",
        "name": "物品显示名称",
        "description": "物品描述",
        "image": "图片文件名"
    }
}
```

## 📝 字段说明

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `id` | 字符串 | ✅ | 物品的唯一标识符 | `"fish_item"` |
| `name` | 字符串 | ✅ | 玩家看到的物品名称 | `"小鱼干"` |
| `description` | 字符串 | ✅ | 物品的详细描述 | `"美味的小鱼干，可以吃或藏起来"` |
| `image` | 字符串 | ✅ | 物品的图片文件名 | `"placeholder_fish_60x30"` |

## 🎮 实际例子

### 小鱼干配置
```json
{
    "fish_item": {
        "id": "fish_item",
        "name": "小鱼干",
        "description": "美味的小鱼干，可以吃或藏起来",
        "image": "placeholder_fish_60x30"
    }
}
```

### 钥匙配置
```json

        "description": "一把神秘的钥匙，可以打开某些门",
```

## ➕ 添加新物品

### 步骤1：准备图片
1. 将物品图片放入 `public/assets/images/` 文件夹
2. 记住图片文件名（不需要扩展名）

### 步骤2：在items.json中添加配置
```json
{
    "新物品ID": {
        "id": "新物品ID",
        "name": "新物品名称",
        "description": "新物品描述",
        "image": "图片文件名"
    }
}
```

### 步骤3：在场景中使用
在场景配置文件中添加物品：
```json
{
    "objects": {
        "新物品实例": {
            "x": 500,
            "y": 300,
            "image": "图片文件名",
            "name": "新物品名称",
            "look": "查看时的描述",
            "actions": ["相关动作ID"]
        }
    }
}
```

## 🔧 常见修改

### 修改物品名称
```json
// 修改前
"name": "小鱼干"

// 修改后
"name": "美味小鱼干"
```

### 修改物品描述
```json
// 修改前
"description": "美味的小鱼干，可以吃或藏起来"

// 修改后
"description": "超级美味的小鱼干，闻起来就让人流口水！"
```

### 修改物品图片
```json
// 修改前
"image": "placeholder_fish_60x30"

// 修改后
"image": "new_fish_image"
```

## ⚠️ 注意事项

### 图片要求
- 图片必须存在于 `public/assets/images/` 文件夹中
- 文件名不包含扩展名（.png, .jpg等）
- 建议使用PNG格式，支持透明背景

### ID命名规则
- 使用小写字母和下划线
- 不能包含空格或特殊字符
- 建议使用有意义的名称
- 例如：`fish_item`, `golden_key`, `toy_mouse`

### 避免重复
- 每个物品的ID必须唯一
- 不能与现有物品ID重复
- 建议在添加前检查现有配置

## 🎯 物品分类建议

根据游戏设计，可以将物品分为以下几类：

### 食物类
- 小鱼干、猫粮、猫条等
- 用于恢复饥饿值

### 工具类
- 钥匙、绳子、纸箱等
- 用于解锁区域或制作陷阱

### 玩具类
- 玩具老鼠、转球、猫咬绳等
- 用于玩耍和娱乐

### 收集类
- 特殊物品、纪念品等
- 用于成就系统

## 🔄 与其他系统的关联

### 与动作系统的关联
物品可以在 `actions.json` 中定义特殊动作：
```json
{
    "item_actions": {
        "fish_item": {
            "eat": {
                "id": "eat_fish",
                "text": "吃掉",
                "log": "小鱼干真好吃！"
            }
        }
    }
}
```

### 与场景系统的关联
物品可以在场景中放置和交互：
```json
{
    "objects": {
        "fish_1": {
            "x": 700,
            "y": 500,
            "image": "placeholder_fish_60x30",
            "name": "小鱼干",
            "actions": ["pickup_fish"]
        }
    }
}
```

## 💡 策划建议

### 物品设计原则
1. **功能明确** - 每个物品应该有明确的用途
2. **描述生动** - 用有趣的语言描述物品
3. **平衡性** - 考虑物品在游戏中的平衡性
4. **主题一致** - 符合猫咪游戏的主题

### 命名建议
- 使用简单易懂的名称
- 避免过于复杂的描述
- 保持语言风格一致
- 考虑玩家的理解能力
