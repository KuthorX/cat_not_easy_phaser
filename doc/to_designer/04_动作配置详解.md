# 动作配置详解

## 🎯 什么是动作配置？

动作配置定义了玩家可以执行的所有交互行为，比如捡起物品、睡觉、玩耍等。每个动作都有特定的效果和条件。

## 📁 配置文件位置

动作配置在 `public/assets/data/actions.json` 文件中。

## 🏗️ 动作配置结构

动作配置分为三个主要部分：

```json
{
    "actions": {
        "动作ID": {
            // 基础动作定义
        }
    },
    "item_actions": {
        "物品ID": {
            "动作类型": {
                // 物品特定动作
            }
        }
    },
    "interactions": {
        "交互ID": {
            // 特殊交互动作
        }
    }
}
```

## 📝 字段说明

### 基础动作字段

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `id` | 字符串 | ✅ | 动作的唯一标识符 | `"pickup_fish"` |
| `text` | 字符串 | ✅ | 动作按钮显示的文字 | `"叼走鱼"` |
| `log` | 字符串 | ✅ | 执行动作后的日志信息 | `"我叼起了一条鱼！"` |
| `category` | 字符串 | ❌ | 动作分类 | `"simple"` 或 `"complex"` |
| `timeCost` | 数字 | ❌ | 时间消耗（分钟） | `30` |
| `effects` | 对象 | ❌ | 动作效果 | 见下方说明 |
| `triggerAchievement` | 字符串 | ❌ | 触发的成就ID | `"fish_pickup"` |

### 效果字段说明

```json
{
    "effects": {
        "progress": {
            "hungry": -15,           // 饥饿值变化
            "humanComingHome": 5     // 人类回家进度
        },
        "inventory": {
            "action": "add",         // "add" 或 "remove"
            "item": "fish_item"      // 物品ID
        },
        "special": {
            "unlockArea": "room_a"   // 解锁区域
        }
    }
}
```

## 🎮 实际例子

### 捡起小鱼干动作
```json
{
    "pickup_fish": {
        "id": "pickup_fish",
        "text": "叼走鱼",
        "log": "我叼起了一条鱼！",
        "effects": {
            "inventory": {
                "action": "add",
                "item": "fish_item"
            },
            "progress": {
                "hungry": -15,
                "happiness": 10
            }
        },
        "triggerAchievement": "fish_pickup"
    }
}
```

### 吃食物动作
```json
{
    "eat_food": {
        "id": "eat_food",
        "text": "吃粮喝水",
        "log": "我吃了猫粮，喝了水，感觉好多了！",
        "category": "simple",
        "timeCost": 30,
        "hungryRestore": 2,
        "effects": {
            "progress": {
                "humanComingHome": 5
            }
        }
    }
}
```

### 物品特定动作
```json
{
    "item_actions": {
        "fish_item": {
            "eat": {
                "id": "eat_fish",
                "text": "吃掉",
                "log": "小鱼干真好吃！",
                "effects": {
                    "progress": { 
                        "hungry": -20, 
                        "humanComingHome": 5 
                    },
                    "inventory": {
                        "action": "remove",
                        "item": "fish_item"
                    }
                }
            }
        }
    }
}
```

## ➕ 添加新动作

### 步骤1：定义基础动作
```json
{
    "actions": {
        "新动作ID": {
            "id": "新动作ID",
            "text": "动作按钮文字",
            "log": "执行后的日志",
            "category": "simple",
            "timeCost": 30,
            "effects": {
                "progress": {
                    "hungry": -10
                }
            }
        }
    }
}
```

### 步骤2：在场景中使用
在场景配置中添加动作：
```json
{
    "objects": {
        "新对象": {
            "actions": ["新动作ID"]
        }
    }
}
```

### 步骤3：定义物品特定动作（可选）
```json
{
    "item_actions": {
        "物品ID": {
            "动作类型": {
                "id": "新动作ID",
                "text": "动作文字",
                "log": "执行日志",
                "effects": {
                    "inventory": {
                        "action": "remove",
                        "item": "物品ID"
                    }
                }
            }
        }
    }
}
```

## 🎯 动作分类

### 简单动作 (simple)
- 时间消耗：30分钟
- 例如：吃食物、喝水、简单玩耍

### 复杂动作 (complex)
- 时间消耗：60分钟
- 例如：深度睡眠、复杂玩耍、制作陷阱

### 即时动作
- 无时间消耗
- 例如：捡起物品、查看物品

## 📊 效果类型详解

### 进度效果 (progress)
影响游戏中的各种进度值：
```json
{
    "progress": {
        "hungry": -15,           // 饥饿值变化
        "energy": 10,            // 精力值变化
        "humanComingHome": 5,    // 人类回家进度
        "happiness": 10,         // 快乐值
        "curiosity": 15          // 好奇心
    }
}
```

### 物品效果 (inventory)
管理玩家背包中的物品：
```json
{
    "inventory": {
        "action": "add",         // "add" 添加物品
        "item": "fish_item"      // 物品ID
    }
}
```

```json
{
    "inventory": {
        "action": "remove",      // "remove" 移除物品
        "item": "fish_item"      // 物品ID
    }
}
```

### 特殊效果 (special)
触发特殊游戏机制：
```json
{
    "special": {
        "unlockArea": "room_a",              // 解锁区域
        "changeSceneState": {                // 改变场景状态
            "object_visible": false
        },
        "triggerEvent": "special_event"      // 触发特殊事件
    }
}
```

### 场景效果 (scene)
改变场景中的对象：
```json
{
    "scene": {
        "action": "spawn_item",      // 生成物品
        "item": "fish_item",
        "position": "drop_position"
    }
}
```

## ⚠️ 注意事项

### 动作ID命名规则
- 使用小写字母和下划线
- 不能包含空格或特殊字符
- 建议使用有意义的名称
- 例如：`pickup_fish`, `sleep_on_sofa`, `scratch_sofa`

### 数值平衡
- 时间消耗要合理
- 效果数值要平衡
- 考虑游戏整体平衡性
- 避免过于极端的效果

### 依赖关系
- 引用的物品ID必须在 `items.json` 中定义
- 引用的成就ID必须在 `achievements.json` 中定义
- 引用的区域ID必须在场景配置中定义

### 文字内容
- 使用生动有趣的语言
- 符合猫咪的视角
- 保持风格一致
- 提供有用的信息

## 🔄 与其他系统的关联

### 与物品系统的关联
动作可以操作 `items.json` 中定义的物品：
```json
{
    "inventory": {
        "action": "add",
        "item": "fish_item"  // 引用items.json中的物品
    }
}
```

### 与场景系统的关联
动作可以改变场景状态：
```json
{
    "scene": {
        "action": "spawn_item",
        "item": "fish_item",
        "position": "drop_position"
    }
}
```

### 与成就系统的关联
动作可以触发成就：
```json
{
    "triggerAchievement": "fish_pickup"  // 引用achievements.json中的成就
}
```

## 💡 策划建议

### 动作设计原则
1. **功能明确** - 每个动作应该有明确的效果
2. **平衡合理** - 考虑动作的成本和收益
3. **有趣生动** - 动作描述要有趣
4. **符合逻辑** - 动作要符合猫咪的行为逻辑

### 效果设计建议
1. **渐进性** - 效果应该循序渐进
2. **多样性** - 提供多种不同的效果
3. **关联性** - 动作之间可以有关联
4. **挑战性** - 提供一定的挑战性

### 时间设计建议
1. **合理分配** - 时间消耗要合理
2. **策略性** - 让玩家需要做出选择
3. **平衡性** - 不同动作的时间成本要平衡
4. **节奏感** - 控制游戏的节奏
