# 项目简述

平面点击型的策略解密游戏，近老式flash密室逃脱游戏。

在12小时的规定时间内进行不同的室内行动，以完成多条不同主线收集剧情的探索乐趣为主要体验点。

# 预期游玩时间

2小时

# 美术风格

2D手绘，线条

# 一句话玩法

以一只宠物猫的第一视角，体验从叫主子起床上班到主子回家一整天的日常。随心所欲对家里进行探索和改造，收集多个的结局。

# 项目预算

有个屁预算，全都打白工

# 可扩展性

设置多个不同的开局（工作日，休息日，迟到日）；

固定物资的随机刷新点；

# 游戏机制

游戏开始于早九点，结束于晚九点。时长有12小时。大部分交互都会消耗时间，使得时间推进。除了具体的交互之外，不会以任何方式推进时间。

时间消耗的最小单位是30分钟。简单，基础或是低难度的交互行为的消耗就为30分钟。举例：吃饭恢复饥饿值，拉屎，抖落尾毛进主人的水杯等

其他所有的交互消耗为60分钟。举例：睡觉恢复精力值，将桌上的东西扫落在地，进行玩耍类交互，进行破坏物件的交互等；

主角小猫有两个状态条，分别是【饥饿值】和【精力值】，可以理解为一类用于特殊交互的能量或货币。

上限均为5点，初始数值均为1点。

最基础的恢复饥饿手段是消耗30分钟时间的交互【吃粮喝水】，能恢复2饥饿值；进阶的恢复手段有收集道具猫条，冻干等进行特殊交互【食用】，能恢复4饥饿值；

最基础的恢复精力手段是消耗30分钟时间的交互【猫窝睡觉】，能恢复2精力值；进阶的恢复手段有在主人房间进行【床上睡觉】，能恢复4精力；

部分行动会要求门槛。如：小猫的饥饿值必须大于等于4才能进行交互【拉屎】

部分行动会要求消耗。如：小猫必须消耗3点精力值才能完成一次交互【全屋跑酷】

要求门槛和要求消耗的情况可以同时出现。

对于重要的能够推进剧情线路的交互，往往会对【饥饿值】和【精力值】有要求。这使得游戏有一定策略规划空间，不会太过无脑。
