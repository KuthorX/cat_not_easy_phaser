# 🐱 猫咪行为扩展设计

## 概述

为了让猫咪游戏更加丰富有趣，我们需要扩展猫咪的行为系统，让每只猫咪都有独特的性格和行为模式。

## 1. 猫咪性格系统

### 性格类型
1. **好奇宝宝 (Curious)** - 喜欢探索新事物
2. **爱玩猫 (Playful)** - 喜欢玩耍和互动
3. **领地守护者 (Territorial)** - 保护自己的地盘
4. **社交达人 (Social)** - 喜欢与人类互动
5. **独立猫 (Independent)** - 喜欢独来独往
6. **懒猫 (Lazy)** - 喜欢休息和睡觉
7. **冒险家 (Adventurous)** - 喜欢冒险和挑战
8. **调皮鬼 (Mischievous)** - 喜欢搞破坏

### 性格特征
```typescript
interface CatPersonality {
    type: string;
    traits: {
        curiosity: number;      // 好奇心 0-100
        playfulness: number;    // 爱玩程度 0-100
        territorial: number;    // 领地意识 0-100
        social: number;         // 社交性 0-100
        independence: number;   // 独立性 0-100
        mischief: number;       // 调皮程度 0-100
    };
    preferences: {
        favoriteSleepSpot: string;
        favoriteToy: string;
        favoriteFood: string;
        leastFavoriteActivity: string;
    };
}
```

## 2. 新增猫咪行为

### 基础行为
- **梳理毛发 (Grooming)** - 保持清洁
- **捕猎 (Hunting)** - 寻找猎物
- **标记领地 (Territory Marking)** - 留下气味
- **看窗外 (Window Watching)** - 观察外界
- **玩植物 (Plant Interaction)** - 与植物互动
- **对音乐反应 (Music Reaction)** - 听到音乐的反应
- **追影子 (Shadow Chasing)** - 追逐光影
- **躲在纸箱里 (Box Hiding)** - 寻找安全感
- **爬到高处 (High Place Climbing)** - 占领制高点
- **与人类互动 (Human Socialization)** - 寻求关注

### 环境互动行为
- **探索新区域 (Area Exploration)** - 发现新地方
- **在阳光下休息 (Sunlight Bathing)** - 享受阳光
- **玩水 (Water Playing)** - 与水互动
- **调查声音 (Sound Investigation)** - 对声音的好奇
- **占领地盘 (Spot Claiming)** - 标记自己的地方

### 高级行为
- **设置陷阱 (Trap Setting)** - 保护领地
- **防御入侵 (Invasion Defense)** - 驱赶入侵者
- **寻找钥匙 (Key Finding)** - 探索隐藏物品
- **解锁房间 (Room Unlocking)** - 扩展活动范围
- **藏食物 (Food Hiding)** - 储存食物

## 3. 行为触发条件

### 时间触发
- 早晨：梳理毛发、晒太阳
- 中午：玩耍、探索
- 下午：休息、看窗外
- 晚上：捕猎、巡逻

### 状态触发
- 饥饿时：寻找食物、捕猎
- 无聊时：玩耍、探索
- 紧张时：躲藏、标记领地
- 开心时：与人类互动、玩耍

### 环境触发
- 听到声音：调查声音
- 看到影子：追逐影子
- 发现新物品：探索
- 遇到其他动物：防御或社交

## 4. 行为效果系统

### 进度影响

interface BehaviorEffect {

### 成就解锁
- 梳理大师：梳理次数达到一定数量
- 捕猎高手：成功捕猎一定次数
- 社交达人：与人类互动达到一定次数
- 探索家：探索所有区域
- 领地守护者：标记领地达到一定次数
