# 成就系统说明

## 概述

成就系统已经重构为完全可配置的独立页面系统，支持成就的自动检查和解锁。

## 主要特性

### 1. 独立页面设计
- **成就页面**: 点击成就按钮跳转到独立的成就页面
- **日志页面**: 点击日志按钮跳转到独立的日志页面
- 页面间可以自由切换，不影响主游戏流程

### 2. 完全可配置化
- 所有成就定义都在 `public/assets/data/achievements.json` 中
- 支持多种成就条件类型
- 支持成就路径和主成就系统

### 3. 自动检查机制
- 动作执行后自动检查成就
- 支持计数器和标志两种触发方式
- 实时更新成就状态

## 系统架构

### 核心组件

1. **AchievementSystem** (`src/systems/AchievementSystem.ts`)
   - 成就系统的核心管理器
   - 负责成就检查、解锁和状态管理

2. **AchievementScene** (`src/scenes/AchievementScene.ts`)
   - 独立的成就展示页面
   - 支持滚动浏览和分类显示

3. **LogScene** (`src/scenes/LogScene.ts`)
   - 独立的日志展示页面
   - 支持日志清空和时间戳显示

4. **AchievementLoader** (`src/utils/AchievementLoader.ts`)
   - 成就配置加载器
   - 支持配置验证和错误处理

## 成就配置格式

### 成就定义
```json
{
  "achievements": {
    "achievement_id": {
      "id": "achievement_id",
      "name": "成就名称",
      "description": "成就描述",
      "category": "destruction|obedient|explorer|strategist",
      "isMainAchievement": false,
      "condition": {
        "type": "counter|flag|all_sub_achievements|human_coming_home_low|all_rooms_unlocked|all_traps_set_and_defend",
        "counter": "计数器名称",
        "flag": "标志名称",
        "value": 数值,
        "humanComingHomeThreshold": 阈值,
        "noDestruction": true
      }
    }
  }
}
```

### 成就路径定义
```json
{
  "achievementPaths": {
    "path_id": {
      "id": "path_id",
      "name": "路径名称",
      "description": "路径描述",
      "mainAchievement": "主成就ID",
      "subAchievements": ["子成就ID1", "子成就ID2"],
      "endCondition": {
        "type": "all_sub_achievements|human_coming_home_low|all_rooms_unlocked|all_traps_set_and_defend",
        "humanComingHomeThreshold": 阈值,
        "noDestruction": true
      }
    }
  }
}
```

## 成就条件类型

### 1. counter (计数器)
- 基于游戏中的计数器触发
- 当计数器达到指定值时解锁成就

### 2. flag (标志)
- 基于游戏中的标志触发
- 当标志设置为true时解锁成就

### 3. all_sub_achievements (所有子成就)
- 当路径中的所有子成就都解锁时，解锁主成就

### 4. human_coming_home_low (人类回家进度低)
- 当人类回家进度低于阈值时解锁成就
- 可选的noDestruction参数检查是否没有破坏活动

### 5. all_rooms_unlocked (所有房间解锁)
- 当所有指定房间都解锁时触发

### 6. all_traps_set_and_defend (所有陷阱设置并防御)
- 当所有陷阱都设置并成功防御入侵时触发

## 计数器系统

游戏内置了以下计数器：

- `waterBowlKnockOverCount`: 打翻水碗次数
- `tableItemPushCount`: 推倒物品次数
- `scratchCount`: 磨爪次数
- `toiletPaperDestroyCount`: 毁掉厕纸次数
- `meowCount`: 喵喵叫次数
- `sleepLocationCount`: 睡觉地点数量
- `litterBoxCount`: 使用猫砂盆次数
- `toyInteractionCount`: 玩具互动次数
- `keyFindCount`: 找到钥匙数量
- `fishHideCount`: 藏小鱼干次数
- `trapSetCount`: 设置陷阱次数
- `invasionDefendCount`: 防御入侵次数

## 标志系统

游戏内置了以下标志：

- `balcony_visited`: 访问阳台
- `room_c_unlocked`: 解锁房间C
- `outside_escaped`: 成功逃脱
- `alarm_set`: 设置警报
- `traps_configured`: 配置陷阱

## 使用方法

### 1. 添加新成就
1. 在 `public/assets/data/achievements.json` 中添加成就定义
2. 定义成就条件和触发逻辑
3. 重启游戏或重新加载配置

### 2. 在代码中触发成就
```typescript
// 增加计数器
achievementSystem.incrementCounter('waterBowlKnockOverCount');

// 设置标志
achievementSystem.setFlag('balcony_visited');

// 手动检查成就
achievementSystem.checkAchievements();
```

### 3. 测试成就系统
使用 `test_achievement_system.html` 页面测试成就系统功能。

## 页面导航

### 从主游戏到成就页面
- 点击右下角的🏆按钮
- 主游戏场景暂停
- 成就页面启动

### 从成就页面返回
- 点击左上角的"返回"按钮
- 成就页面停止
- 主游戏场景恢复

### 从主游戏到日志页面
- 点击右下角的📖按钮
- 主游戏场景暂停
- 日志页面启动

## 技术细节

### 场景管理
- 使用Phaser的场景系统管理页面切换
- 支持场景暂停和恢复
- 保持游戏状态的一致性

### 事件系统
- 成就解锁时发送事件通知
- UI场景监听成就事件并显示弹窗
- 支持实时成就状态更新

### 数据持久化
- 成就状态保存在游戏状态中
- 支持存档和读档
- 成就进度不会丢失

## 扩展性

### 添加新的成就条件类型
1. 在 `AchievementCondition` 接口中添加新类型
2. 在 `checkAchievementCondition` 方法中实现检查逻辑
3. 更新配置验证逻辑

### 添加新的计数器
1. 在 `GameState` 接口的 `achievementCounters` 中添加新字段
2. 在游戏逻辑中调用 `incrementCounter` 方法

### 添加新的标志
1. 在游戏逻辑中调用 `setFlag` 方法
2. 标志会自动添加到 `GameState.flags` 中

## 故障排除

### 成就不触发
1. 检查计数器名称是否正确
2. 检查标志名称是否正确
3. 确认成就配置格式正确
4. 查看控制台日志

### 页面切换问题
1. 确认场景已正确注册
2. 检查场景键名是否正确
3. 确认事件监听器已正确设置

### 配置加载失败
1. 检查JSON文件格式
2. 确认文件路径正确
3. 查看网络请求状态
