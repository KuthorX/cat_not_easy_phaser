# 实现方案

本文档根据《策划案.md》和《技术方案.md》的要求，提供一个详细的游戏代码实现方案和说明。

## 1. 概述 (Overview)

本项目旨在开发一款基于 Phaser 3 引擎的2D平面点击解密游戏。玩家扮演一只猫，在室内环境中进行探索和互动，通过不同的选择达成多种结局。

核心特性：
- **引擎**: Phaser 3
- **架构**: 数据驱动的场景式架构
- **交互**: 点击/悬停驱动的事件系统
- **平台**: Web 浏览器

## 2. 项目结构 (Project Structure)

为了保证代码的清晰和可维护性，项目将采用以下目录结构：

```
maobuyi/
├── assets/
│   ├── data/      # 游戏数据 (JSON格式)
│   │   └── gameData.json
│   └── images/    # 游戏图片资源 (场景背景、物体等)
├── src/
│   ├── objects/   # 可交互对象等游戏对象类
│   │   └── Interactable.js
│   ├── scenes/    # 游戏场景类
│   │   ├── BootScene.js
│   │   ├── UIScene.js
│   │   └── GameScene.js
│   └── systems/   # 核心系统模块
│       └── GameState.js
├── .gitignore     # Git忽略文件配置
├── index.html     # 游戏入口HTML文件
├── main.js        # 游戏主逻辑与启动配置
└── README.md      # 项目说明与运行指南
```

## 3. 核心模块设计 (Module Design)

### 3.1. 游戏主入口 (`main.js`)
- **职责**: 初始化 Phaser 游戏实例，配置全局参数（如画布大小、物理引擎等），并加载所有游戏场景。

### 3.2. 场景 (`src/scenes/`)
游戏将由多个场景构成，切换场景即代表着切换地点或视角。

- **`BootScene.js`**: 启动场景。负责加载最核心的资源，例如后续场景需要用到的资源清单、Loading画面等，加载完毕后会启动主游戏场景。
- **`GameScene.js`**: 核心游戏场景。这是一个通用的场景类，负责：
    1.  根据传入的场景ID，从 `gameData.json` 中读取并显示对应的背景图片。
    2.  根据场景数据，动态创建该场景内所有的可交互对象 (`Interactable`)。
    3.  处理场景内的导航（例如点击箭头切换到另一个 `GameScene`）。
- **`UIScene.js`**: UI场景。该场景将始终在 `GameScene` 之上运行，专门用于渲染和管理所有UI元素，如：
    -   对话框/提示框
    -   交互选项菜单
    -   游戏内时间显示
    -   "猫后脑勺"界面
    -   背包界面

### 3.3. 可交互对象 (`src/objects/Interactable.js`)
这是一个代表了场景中所有可点击/互动物体的基类。
- **属性**: 名称、贴图（图片）、位置、交互提示、点击后的行为等。
- **行为**:
    -   鼠标悬停时，显示高亮效果（如黄色边框）和提示文字。
    -   鼠标点击时，根据 `gameData.json` 中定义的交互类型，触发相应事件（例如：显示一段描述文字、切换到新场景、更新游戏状态等）。

### 3.4. 游戏状态 (`src/systems/GameState.js`)
这是一个全局单例对象，用于存储和管理整个游戏的持久化状态。
- **管理内容**:
    -   游戏内时间（12小时倒计时）。
    -   已解锁的区域和关键剧情节点（Flags）。
    -   "背包"中的物品。
    -   各项结局的达成进度。
- **作用**: 方便任何场景和对象随时存取游戏状态，做出对应的逻辑判断。

## 4. 数据驱动设计

为了将游戏逻辑与游戏内容分离，方便策划随时调整，我们将采用数据驱动的设计。

### `assets/data/gameData.json`
这个文件是游戏的核心数据库，采用JSON格式定义了所有场景和对象。

**示例结构**:
```json
{
  "scenes": {
    "living_room_north": {
      "background": "living_room_north.png",
      "objects": [
        { "id": "sofa", "x": 100, "y": 200 },
        { "id": "tv", "x": 500, "y": 200 }
      ],
      "nav": [
        { "to": "hallway", "area": [/* 导航热区 */] }
      ]
    },
    "hallway": { ... }
  },
  "objects": {
    "sofa": {
      "name": "沙发",
      "image": "sofa.png",
      "interactions": [
        { "type": "look", "text": "一个普通的沙发，很适合磨爪子。" },
        { "type": "action", "action": "scratch_sofa", "text": "磨爪子" }
      ]
    },
    "tv": { ... }
  },
  "gameState": {
      "currentTime": "9:00",
      "unlockedAreas": ["living_room_north", "hallway"],
      "inventory": []
  }
}
```

## 5. 开发与运行

1.  **环境**: 无需复杂环境，一个支持HTTP服务的环境即可。推荐使用 `Node.js` 的 `http-server` 包。
2.  **运行**:
    -   安装 `http-server`：`npm install -g http-server`
    -   在项目根目录运行：`http-server`
    -   在浏览器中打开对应的地址。
3.  **资源**: 初期所有图片资源将使用"黑底黄框白字"的占位符代替，以快速推进功能开发。

此方案将逻辑、数据和资源清晰分离，使项目易于扩展和维护，非常适合独立或小团队开发。
