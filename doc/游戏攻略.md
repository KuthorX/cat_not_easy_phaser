# 猫咪不是好惹的 - 游戏攻略

## 游戏简介

《猫咪不是好惹的》是一款以猫咪为主角的文字冒险游戏。玩家扮演一只猫咪，在两脚兽（主人）回家前的有限时间内，通过各种行为来解锁不同的成就。游戏有四个主要成就路径，每个路径都有独特的玩法和结局。

## 游戏机制

### 基础属性
- **饥饿度 (hungry)**: 需要定期进食，达到100%会游戏结束
- **如厕需求 (needPoop)**: 需要定期使用猫砂盆，达到100%会游戏结束
- **两脚兽回家进度 (humanComingHome)**: 各种行为会增加这个进度，达到100%游戏结束

### 物品系统
- **小鱼干**: 可以吃掉恢复饥饿度，也可以藏起来
- **钥匙**: 用于解锁房间门

## 成就系统详解

### 1. 完美拆家王 (Destruction Path)

**路径描述**: 作为一个精力旺盛的猫，把制造混乱作为首要目标

#### 子成就：

**🏆 水漫金山 (water_overflow)**
- **条件**: 打翻所有水碗 (waterBowlKnockOverCount >= 3)
- **方法**: 找到所有水碗并使用"打翻"动作

**🏆 天降正义 (table_justice)**
- **条件**: 将桌子上的特定物品推到地上 (tableItemPushCount >= 2)
- **方法**: 找到桌子上的物品并使用"推下去"动作

**🏆 沙发毁灭者 (sofa_destroyer)**
- **条件**: 对沙发执行磨爪达到一定次数 (scratchCount >= 5)
- **方法**: 找到沙发并使用"磨爪"动作

**🏆 厕纸终结者 (toilet_paper_terminator)**
- **条件**: 毁掉卷纸 (toiletPaperDestroyCount >= 1)
- **方法**: 在过道找到厕纸并使用"撕碎"动作

#### 主成就：
**🏆 今日最佳破坏王 (best_destroyer)**
- **条件**: 在两脚兽回家前，达成所有破坏系列子成就
- **要求**: 完成所有4个子成就，且两脚兽回家进度 <= 100

---

### 2. 温顺的乖猫 (Obedient Path)

**路径描述**: 讨好两脚兽，做一个安静、可爱的陪伴者

#### 子成就：

**🏆 饭来张口 (food_beggar)**
- **条件**: 通过喵喵叫等互动从智人处获得食物 (meowCount >= 3)
- **方法**: 使用"喵喵叫"动作3次

**🏆 午后小憩 (afternoon_nap)**
- **条件**: 在所有指定的地点都睡过觉 (sleepLocationCount >= 3)
- **方法**: 在沙发、猫别墅、猫窝分别睡觉

**🏆 清洁标兵 (clean_champion)**
- **条件**: 在猫砂盆里完成所有如厕需求 (litterBoxCount >= 5)
- **方法**: 使用猫砂盆5次

**🏆 玩具爱好者 (toy_lover)**
- **条件**: 与所有玩具类物品进行过互动 (toyInteractionCount >= 3)
- **方法**: 与玩具互动3次

#### 主成就：
**🏆 智人首席奴才 (chief_servant)**
- **条件**: 完成所有温顺行为且未进行任何破坏活动
- **要求**: 完成所有4个子成就，且没有任何破坏行为

---

### 3. 大冒险家 (Explorer Path)

**路径描述**: 对外界充满好奇，探索所有未知的领域

#### 子成就：

**🏆 阳台巡视者 (balcony_patrol)**
- **条件**: 成功到达阳台 (balcony_visited = true)
- **方法**: 找到通往阳台的路径并访问

**🏆 钥匙猎人 (key_hunter)**
- **条件**: 找到并获取所有关键钥匙 (keyFindCount >= 3)
- **方法**: 在游戏中找到3把钥匙

**🏆 门缝里的大秘密 (door_secret)**
- **条件**: 解开并进入房间C (room_c_unlocked = true)
- **方法**: 使用钥匙解锁房间C的门

**🏆 越狱大师 (escape_master)**
- **条件**: 找到打开外门的方法并成功离家出走 (outside_escaped = true)
- **方法**: 找到外门并成功逃出

#### 主成就：
**🏆 这个家我说了算 (home_master)**
- **条件**: 成功进入所有上锁的房间
- **要求**: 完成所有4个子成就

---

### 4. 阴谋家 (Strategist Path)

**路径描述**: 充满警惕与智慧，为潜在的威胁做好准备

#### 子成就：

**🏆 战略储备 (strategic_reserve)**
- **条件**: 将所有小鱼干藏到指定地点 (fishHideCount >= 3)
- **方法**: 将小鱼干藏在沙发下、猫别墅、猫窝等地方

**🏆 高地防御 (high_ground_defense)**
- **条件**: 将特定物品布置在高处，作为防御工事 (trapSetCount >= 3)
- **方法**: 设置3个陷阱

**🏆 入侵者警报 (invasion_alarm)**
- **条件**: 在门口设置一个能发出声响的警报器 (alarm_set = true)
- **方法**: 在过道设置警报器

**🏆 王之蔑视 (king_contempt)**
- **条件**: 成功触发隔壁的猫入侵事件，并用陷阱将其吓走 (invasionDefendCount >= 1)
- **方法**: 成功防御一次入侵

#### 主成就：
**🏆 家庭安全顾问 (security_advisor)**
- **条件**: 成功布置好所有陷阱，并抵御隔壁的猫入侵事件
- **要求**: 完成所有4个子成就

## 游戏场景

### 客厅 (living_room)
- **可交互物品**: 沙发、水碗、猫别墅、猫窝、玩具
- **主要动作**: 睡觉、磨爪、喝水、玩耍

### 过道 (hallway)
- **可交互物品**: 房间门、厕纸、陷阱位置、警报位置
- **主要动作**: 开门、撕厕纸、设置陷阱、设置警报

### 阳台 (balcony)
- **可交互物品**: 阳台区域
- **主要动作**: 巡视

## 游戏技巧

### 时间管理
- 每个动作都会增加两脚兽回家进度
- 破坏类动作增加进度较多
- 温顺类动作增加进度较少

### 资源管理
- 小鱼干可以恢复饥饿度，也可以藏起来
- 钥匙是解锁房间的关键物品
- 合理分配时间在不同成就路径上

### 成就策略
1. **破坏王路线**: 快速完成破坏动作，注意时间控制
2. **温顺路线**: 避免任何破坏行为，专注温顺动作
3. **探索路线**: 寻找钥匙和门，探索所有区域
4. **策略路线**: 设置陷阱和警报，准备防御

## 游戏结局

游戏会在以下情况结束：
- 两脚兽回家进度达到100%
- 饥饿度达到100%
- 如厕需求达到100%

根据解锁的成就路径，会获得不同的结局评价。

## 小贴士

1. **多存档**: 不同成就路径需要不同的策略，建议多存档尝试
2. **观察进度**: 注意观察各项进度，合理规划行动
3. **探索地图**: 仔细探索每个场景，寻找隐藏的物品和路径
4. **成就组合**: 可以尝试同时解锁多个成就路径的子成就
