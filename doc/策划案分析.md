# 策划案分析 - 新游戏机制与成就系统调整

## 新游戏机制分析

根据最新的策划案，游戏机制发生了重大变化：

### 1. 时间系统
- **游戏时长**: 12小时（早9点到晚9点）
- **时间消耗**: 每个交互都会消耗时间
- **最小时间单位**: 30分钟
- **简单交互**: 30分钟（吃饭、拉屎、抖落尾毛等）
- **复杂交互**: 60分钟（睡觉、破坏物件、玩耍等）

### 2. 状态系统
- **饥饿值**: 上限5点，初始3点
- **精力值**: 上限5点，初始3点
- **恢复机制**:
  - 基础恢复：30分钟交互，恢复2点
  - 进阶恢复：60分钟交互，恢复4点

### 3. 交互门槛
- **饥饿值门槛**: 某些行动需要饥饿值≥4
- **精力值消耗**: 某些行动需要消耗精力值
- **策略规划**: 重要剧情交互需要合理规划状态值

## 需要修改的内容

### 1. 游戏状态类型 (GameState)
**当前问题**: 
- 使用百分比进度系统（hungry, needPoop等）
- 没有时间系统
- 没有精力值系统

**需要修改**:
- 添加时间系统（currentTime, timeRemaining）
- 修改状态值为点数系统（hungry: 0-5, energy: 0-5）
- 移除不需要的进度值

### 2. 成就系统重新设计
**当前问题**:
- 成就基于计数器系统
- 没有考虑新的时间限制和状态要求
- 成就路径不符合新的剧情线路

**需要修改**:
- 重新设计成就条件，考虑时间限制
- 添加状态值要求
- 根据新剧情线路重新设计成就

### 3. 动作系统调整
**当前问题**:
- 动作没有时间消耗
- 没有状态值要求
- 没有状态值消耗

**需要修改**:
- 添加时间消耗
- 添加状态值要求
- 添加状态值消耗/恢复

## 新的成就系统设计

### 主线剧情成就（单局内完成）
1. **【玩耍时光】** - 收集所有猫玩具并进行所有玩耍交互
2. **【猫中哈士奇】** - 破坏所有昂贵的可破坏物
3. **【两脚兽的盟友】** - 无破坏行为 + 门口迎接
4. **【再见了两脚兽今天我就要远航】** - 离家出走路线
5. **【走路小心点】** - 布置陷阱陷害铲屎官
6. **【后勤官】** - 准备材料构筑堡垒

### 成就条件类型
- **时间限制**: 必须在特定时间前完成
- **状态要求**: 需要特定饥饿值/精力值
- **状态消耗**: 某些行动需要消耗状态值
- **路径完成**: 完成特定系列行动

## 代码修改说明

### 为什么需要彻底修改成就系统？

1. **游戏机制根本性变化**: 从百分比进度系统改为时间+状态值系统
2. **成就逻辑完全不同**: 新成就基于剧情线路而非行为计数
3. **条件检查方式改变**: 需要检查时间、状态值而非简单的计数器
4. **用户体验优化**: 新系统更符合策划案的设计理念

### 修改的具体原因

1. **时间限制**: 原系统没有时间概念，新系统需要在12小时内完成
2. **状态管理**: 原系统使用百分比，新系统使用点数（0-5）
3. **成就目标**: 原成就基于行为统计，新成就基于剧情完成
4. **交互机制**: 原系统无消耗，新系统有时间+状态值消耗
5. **策略性**: 新系统需要玩家合理规划时间和状态值

这些修改将使游戏更符合策划案的设计意图，提供更好的策略性和可玩性。
