1. 测试基础动作（喝水、睡觉、磨爪）
2. 测试破坏类动作（打翻水碗、推桌子物品）
3. 测试探索类动作（找到钥匙、解锁房间）
4. 测试策略类动作（设置陷阱、防御入侵）
5. 验证成就解锁和游戏结束条件

## 启动方法 🚀

### 使用npm和Node.js（推荐）
1. 启动游戏服务器：`npm run server` 或 `npx tsx server/index.ts`
2. 启动游戏客户端：`npm run dev` 或 `npx vite`
3. 同时启动客户端和服务器：`npm run dev:full`
4. 在游戏中执行不同动作来触发成就
5. 查看成就弹窗和解锁的成就
6. 完成成就线路获得不同的游戏结局

### 端口说明
- 游戏服务器：http://localhost:3000
- 游戏客户端：http://localhost:5173
