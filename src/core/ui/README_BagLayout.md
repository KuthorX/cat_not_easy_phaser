## 物品容器设计

### 容器尺寸
- **宽度**: 300px
- **高度**: 100px
- **间距**: 左右列间距400px，上下行间距120px

### 内容布局
每个物品容器包含：

1. **图标区域** (50x50px)
   - 位置：左侧
   - 背景：深灰色边框

2. **信息区域** (200px宽度)
   - **物品名称**: 14px，粗体，稀有度颜色
   - **类型和稀有度**: 10px，灰色
   - **描述**: 9px，浅灰色，自动换行
   - **使用条件**: 8px，红色（如果有条件）

3. **数量区域** (右侧)
   - **当前数量**: 12px，粗体，白色
   - **最大堆叠**: 9px，浅灰色

### 交互功能

1. **选择高亮**
   - 绿色边框和半透明背景
   - 点击物品时显示

2. **操作按钮**
   - **使用按钮**: 蓝色背景，检查使用条件
   - **丢弃按钮**: 红色背景，直接丢弃

3. **条件检查**
   - 不满足使用条件时，使用按钮变灰
   - 显示具体的使用条件

## 颜色系统

### 稀有度颜色
- **普通 (common)**: 白色 (#FFFFFF)
- **优秀 (uncommon)**: 绿色 (#1EFF00)
- **稀有 (rare)**: 蓝色 (#0070DD)
- **史诗 (epic)**: 紫色 (#A335EE)
- **传说 (legendary)**: 橙色 (#FF8000)

### 背景颜色
- **普通**: 深灰色 (#333333)
- **优秀**: 深绿色 (#1E3A1E)
- **稀有**: 深蓝色 (#1E1E3A)
- **史诗**: 深紫色 (#3A1E3A)
- **传说**: 深橙色 (#3A2A1E)

## 响应式设计

### 字体大小调整
- 所有字体都比原来的设计小1-2px
- 确保在较小的容器中仍然清晰可读

### 文本换行
- 描述文本限制在200px宽度内
- 自动换行避免溢出

### 交互区域
- 点击区域覆盖整个物品容器
- 300x100px的交互区域

## 性能优化

### 渲染优化
- 只渲染有物品的容器
- 空容器设置为不可见

### 内存管理
- 显示时创建容器
- 隐藏时销毁容器
- 避免内存泄漏

## 扩展性

### 物品数量
- 当前支持最多8个物品
- 如需更多物品，可调整网格布局

### 容器大小
- 可调整容器尺寸适应不同需求
- 保持2x4网格的对称性

### 信息显示
- 可添加更多物品信息
- 保持布局的整洁性
