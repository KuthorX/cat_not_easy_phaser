# 🐱 猫咪的一日

一款基于 Phaser 3 引擎的2D平面点击解密游戏。玩家扮演一只猫，在室内环境中进行探索和互动，通过不同的选择达成多种结局。

## 🎮 游戏特色

- **猫咪视角**：以宠物猫的第一视角体验从主人上班到回家的一整天
- **自由探索**：随心所欲对家里进行探索和改造
- **多重结局**：通过不同选择达成多种结局
- **成就系统**：丰富的成就系统，记录你的猫咪生活
- **进度管理**：管理饥饿、拉屎、主人回家等进度条

## 🚀 快速开始

### 方法一：一键启动（推荐）

1. **确保环境**：
   - Python 3.7+
   - Node.js 18+

2. **运行启动脚本**：
   ```bash
   cd run_it
   python quick_start.py
   ```

3. **开始游戏**：
   - 脚本会自动启动服务器并打开浏览器
   - 访问 http://localhost:3000 开始游戏

### 方法二：手动启动

1. **安装依赖**：
   ```bash
   npm install
   ```

2. **启动开发服务器**：
   ```bash
   npm run dev
   ```

3. **打开浏览器**：
   - 访问 http://localhost:3000

## 🎯 游戏玩法

### 核心机制
- **进度条管理**：左上角三个进度条分别代表"两脚兽回家"、"我饿了"、"我要拉屎了"
- **物品交互**：点击场景中的物品进行交互
- **背包系统**：收集和使用各种物品
- **成就解锁**：完成各种行为解锁成就

### 操作说明
- **左键点击**：与物品交互
- **右键点击**：显示物品菜单
- **拖拽物品**：将物品拖到场景中
- **右下角按钮**：
  - 📖 查看游戏日志
  - 🏆 查看成就系统
  - 💾 保存游戏
  - 📂 读取存档

### 游戏目标
- 探索所有区域（客厅、过道、阳台等）
- 完成各种成就（破坏王、乖猫咪、探险家等）
- 体验不同的结局

## 🏆 成就系统

### 成就分类
1. **日常行为**：喝水、睡觉、收集小鱼干等
2. **破坏王**：打翻物品、磨爪、破坏家具等
3. **乖猫咪**：安静睡觉、不搞破坏等
4. **探险家**：探索所有区域、巡逻等

### 主线成就
- **今日最佳破坏王**：完成破坏王路线
- **智人首席奴才**：完成乖猫路线
- **这个家我说了算**：完成冒险家路线

## 🗺️ 游戏区域

### 可探索区域
- **客厅**：主要活动区域，包含沙发、电视、猫别墅等
- **过道**：连接各个房间的通道
- **阳台**：可以巡逻和观察外界
- **房间A/B/C**：需要特定条件解锁的区域

## 🛠️ 技术栈

- **游戏引擎**：Phaser 3
- **开发语言**：TypeScript
- **构建工具**：Node.js + npm
- **服务器**：Express.js
- **数据格式**：JSON

## 🔧 开发说明

